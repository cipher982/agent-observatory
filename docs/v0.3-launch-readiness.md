# Agent Observatory v0.3 Launch Readiness

Status as of 2026-06-03 15:59 EDT: **not public-GO yet**.

The 0.3 safe-capture architecture and automated release candidate gates are in
place. The remaining blockers are public-distribution and live installed-system
proof, not the source-aware capture policy itself.

- `dist/Agent-Observatory-0.3.0-macOS.dmg` exists.
- `dist/Agent-Observatory-0.3.0-macOS.zip` exists.
- `dist/agents version` reports `agent-observatory 0.3.0`.
- `make release` passes and regenerates signed app, DMG, zip, helper, and

## Remaining Public-GO Gates

- Configure notary credentials, notarize and staple the 0.3.0 app and DMG, then
  run `make release-qa`.
- Run `make v03-installed-daemon-compat-qa` after installing the rebuilt app and
  before enabling live capture, especially during upgrade testing.
- Install the 0.3.0 app from `/Applications` and verify system extension
  `0.3.0/7` is `[activated enabled]`.
- Run `make v03-installed-ne-proof` and record the output.
- Run live Claude Code and Codex requests through the installed
  NetworkExtension and verify each request both completes and appears as a full
  capture.
- Decide Gemini CLI release state: promote only with live proof, otherwise keep
  it marked `candidate`.
- Run a real unsupported/custom provider-bound client through the installed
  NetworkExtension and verify it completes, produces no body capture, and appears
  in `/api/coverage` as pass-through.
- Confirm `agents doctor wire` still reports stale Hatch/OpenCode as diagnostic
  instead of a launch blocker.
